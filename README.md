# My Games V3

My Games V3 is a personal game archive for keeping your game library, play history, screenshots, and gaming habits in one place.

The app treats a game as more than a static list item. It focuses on the user's relationship with each game: where it was played, how much time was spent, whether it is completed or still active, what rating or review it has, whether it is a favorite, which screenshots belong to it, and how it lines up with Steam data.

## What It Offers

- Game library: add, edit, delete, filter, and sort games.
- Status tracking: completed, actively playing, abandoned, or planned for later.
- Favorite games: highlight favorite games on the profile.
- Ratings and reviews: add personal notes, scores, and written reviews.
- Screenshots: keep a screenshot archive tied to games and browse random captures.
- Steam integration: Steam profile linking, game import, sync, and conflict resolution.
- Activity feed: game additions, completions, ratings, reviews, and social activity.
- Notifications: completion, review, and social activity notifications.
- Statistics: summaries by platform, status, genre, and play time.
- Import/export: bring a library in from files or export it out.

## Who It Is For

This project is for players who want a tidy record of their gaming history and want to combine Steam data, manual entries, and screenshots around a single library.

## App Areas

- Home: high-level summaries and recent games.
- Games: library management.
- Game detail: game information, user notes, and screenshots.
- Profile: user information, favorites, and activity.
- Social: users, activity, and notifications.
- Steam sync: importing Steam data and resolving conflicts.
