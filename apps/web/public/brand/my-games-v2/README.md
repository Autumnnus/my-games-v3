# My Games · Logo v2

Kullanıcının seçtiği yön: **oyun kumandası + kütüphane**. Kumanda oyun oynamayı, arkasındaki iki kart kişisel oyun koleksiyonunu temsil eder. Önceki M/oynat simgesi bu tasarımda yerini yeni sembole bırakır. Mint renk yönü ve My Games yazısının görünümü korunmuştur.

## Dosyalar

| Dosya | Kullanım | Boyut |
|---|---|---|
| `app-icon.png` | Yeni uygulama ikonu; opak, kare master | 1254 × 1254 px |
| `logo-on-white.png` | Beyaz zeminli yatay logo | 1983 × 793 px |
| `logo-on-dark.png` | Koyu zeminli yatay logo | 1983 × 793 px |
| `previous-app-icon.png` | Sadece önce/sonra karşılaştırması için eski ikon | 1254 × 1254 px |
| `preview.html` | Logo kullanımları ve ikon karşılaştırması | HTML |
| `generation-prompts.json` | Nihai üretim promptları | JSON |
| `my-games-logo-kit.zip` | Tüm v2 final dosyaları | ZIP |

Dosyalar built-in `image_gen` ile üretilmiş raster PNG'lerdir. Şeffaf veya SVG değillerdir. Hedef palet mint `#7EE2A8`, kömür `#0B0C10` ve beyaz `#F4F5F7`; üretimden kaynaklanan hafif ton farklılıkları vardır.

Kare ikonun yuvarlatılmış köşeleri yalnızca HTML önizlemede gösterilir. Logoların en-boy oranını koruyarak kullan. Büyük baskılar için ayrıca vektör master hazırlanmalıdır.

V1 dosyaları `../my-games-v1/` klasöründe durur. Uygulamanın canlı logosu ve favikonu bu çalışma kapsamında değiştirilmedi.
